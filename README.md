# Precios para Rendi

Cada mañana se leen los precios que Lider, Unimarc, Jumbo, Santa Isabel, Tottus y Alvi muestran en sus páginas públicas para los productos del recetario de Rendi, y se guardan en `precios.json`. La app descarga ese archivo al abrirse.

`registro.txt` muestra qué producto se eligió en cada cadena, para revisar que calce.
